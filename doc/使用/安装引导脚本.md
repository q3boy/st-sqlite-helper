# 安装引导脚本

角色卡依赖酒馆sqlite助手时，作者可以随卡附带一个独立的酒馆助手脚本。玩家加载脚本后，它检查插件是否安装；缺少插件时先征求玩家同意，再从[正式仓库](https://github.com/q3boy/st-sqlite-helper)安装。玩家必须先安装并启用[酒馆助手 JS-Slash-Runner](https://github.com/N0VI028/JS-Slash-Runner)。

脚本完整自包含，取得、导入和运行它都不需要先安装 SQLite Helper 或 DVS。它是可选附带内容，不负责业务注册、数据库初始化或插件更新。

## 下载与选择

从正式仓库取得以下一种文件：

| 接入方式 | 下载文件 |
| --- | --- |
| 在酒馆助手界面导入 | [sqlite-helper-install.json](https://raw.githubusercontent.com/q3boy/st-sqlite-helper/master/installer/sqlite-helper-install.json) |
| 使用 tavern_sync 打包角色卡 | [sqlite-helper-install.js](https://raw.githubusercontent.com/q3boy/st-sqlite-helper/master/installer/sqlite-helper-install.js) |

JSON 与 JS 是两种替代方式，同一张卡只保留一个安装引导脚本。安装引导与原有 Helper／DVS 业务脚本分别保留；业务脚本继续按原有方式等待接口并注册，不要把引导代码放进等待插件的业务脚本中。

## 在酒馆助手中导入 JSON

1. 下载 `sqlite-helper-install.json`。
2. 在酒馆助手中将它导入到该角色的脚本范围。
3. 打开角色脚本范围的总开关，并手动启用导入后的“酒馆sqlite助手安装引导”，确认角色中只保留一个副本，再按酒馆助手原生方式随角色卡导出。

已核对的酒馆助手原生单脚本导入会重新分配脚本 ID，并将脚本设为停用，因此导入后需要手动启用。发行文件使用固定 ID `01a15a6c-8e86-70c4-9fce-c9729b904c2b`；原生导入后以实际生成的 ID 为准。

## 使用 tavern_sync 打包 JS

下载 `sqlite-helper-install.js` 到角色卡的脚本目录，在现有角色卡 YAML 的 `扩展字段.酒馆助手.脚本库` 中加入以下条目：

```yaml
扩展字段:
  酒馆助手:
    脚本库:
      - 名称: 酒馆sqlite助手安装引导
        id: 01a15a6c-8e86-70c4-9fce-c9729b904c2b
        启用: true
        类型: 脚本
        文件: 脚本/sqlite-helper-install.js
        数据: {}
        按钮:
          启用: false
          按钮列表: []
```

`文件` 指向实际下载的本地 JS，路径按你的角色卡目录调整。已有 `扩展字段`、`酒馆助手` 或 `脚本库` 时合入现有结构，不重复创建同名 YAML 键。显式保留上述 `id`，它由 YAML 提供，JS 不会自行生成脚本 ID。安装引导不需要设置 `dvs_enable`。

使用你已有的 tavern_sync `bundle <配置名>` 流程，将完整 JS 嵌入角色卡后再分发。

## 玩家会看到什么

| 当前情况 | 脚本的行为 |
| --- | --- |
| 已安装且启用 | 结束本次检查，不提示安装 |
| 已安装但停用 | 提示在扩展管理中启用指定扩展，再刷新页面；不代为启用 |
| 已安装，当前页面尚未识别 | 提示刷新页面，不重复安装 |
| 确认缺少插件 | 显示正式仓库、安装范围及刷新说明；点击“安装插件”才发起一次安装 |
| 取消、关闭提示或按 Esc | 结束本次执行；下次脚本加载时重新检查 |
| 安装成功 | 再次询问是否刷新；选择“稍后刷新”会保留安装，稍后手动刷新即可 |
| 检查或安装失败 | 显示实际错误和手动安装地址，结束本次执行，不自动重试 |

脚本每次加载只检查一次；检查失败时不会将插件当作未安装。识别到安装不表示数据库服务或 DVS 已就绪，业务脚本仍需等待相应接口。

管理员确认安装时供酒馆全部账号使用，其他账号仅为当前账号安装，实际范围会在确认框中说明。安装成功只表示原生安装请求成功，插件需刷新页面后生效；刷新失败时按提示手动刷新，无需重复安装。

安装后按[使用与维护指南](../sqlite-helper/指南/使用与维护指南.md#安装后的首次使用)完成存储与服务设置。此脚本不检查版本或更新插件，后续更新使用[原生扩展更新流程](../sqlite-helper/指南/使用与维护指南.md#更新步骤)。
