# 使用导航

酒馆sqlite助手包含两部分：Helper 为酒馆助手脚本提供 SQLite 数据库；DVS 使用 Helper 管理角色卡中随 AI 回复变化的状态。人物设定、业务字段、初值和更新规则由作者决定。

安装前确认取得完整扩展包。安装入口、必需依赖、浏览器要求和更新操作统一见[使用与维护指南](../sqlite-helper/指南/使用与维护指南.md#安装与更新)。

## 玩家

1. 安装并启用酒馆助手和 SQLite Helper 后，按[安装后的首次使用](../sqlite-helper/指南/使用与维护指南.md#安装后的首次使用)打开扩展设置。自动检测完成后点「使用推荐设置并刷新」。
2. 日常游玩使用推荐的存储即可。要用本机 SQLite 工具修改数据，切换到制卡模式，保存并刷新。首次点「选择数据目录」，已有授权目录可直接使用，失去权限时点「重新授权」。切换模式时原数据留在原处。详见[授权制卡目录](../sqlite-helper/指南/使用与维护指南.md#授权制卡目录)。
3. 使用 DVS 卡片时，打开“扩展设置 → DVS → 模型配置”，填写名称、接口地址、模型和服务所需的密钥，点「保存」。第一份配置会自动用于变量更新。卡片决定是否启用输入增强，使用哪个模型由玩家在酒馆的“功能使用”中选择，也可跟随变量更新。切换卡片后沿用这个选择。正文模型仍在酒馆自己的连接设置中选择。详见[模型配置说明](../dvs/指南/DVS作者使用手册.md#配置变量模型)。
4. 在[数据库查看器](../sqlite-helper/指南/使用与维护指南.md#sqlite-数据库查看器)查看数据；需要清理删除角色或聊天后留下的数据时，按[扫描与修复](../sqlite-helper/指南/使用与维护指南.md#扫描与修复)先扫描、核对，再执行。

遇到提示先看[故障处理](../sqlite-helper/指南/使用与维护指南.md#遇到故障时)。写入返回后仍可能尚未保存，不要立即关闭服务或重新加载，也不要因等待过久直接重复提交。

## Helper 脚本作者

1. 从[完整笔记示例](../../examples/helper-notes/README.md)开始，在专用单人聊天中运行 `notes.js`，核对建表、绑定参数写入、查询和重复运行。
2. 阅读[业务侧使用指南](../sqlite-helper/指南/业务侧使用指南.md)，决定数据库范围、代理持有时间、哪些命令必须共同提交，以及错误时怎样停止后续动作。
3. 接口细节按需查[公共接口契约](../sqlite-helper/契约/公共接口契约.md)、[数据库与保存契约](../sqlite-helper/契约/数据库与保存契约.md)及[错误说明](../sqlite-helper/指南/错误说明.md)。编辑器类型使用扩展包中的 `types/sqlite-helper.d.ts`。

Helper 示例不需要 DVS 卡片或状态栏。完整实现只在示例源文件维护，指南解释它使用的接口和行为。

要随卡附带可选的插件安装提示，按[安装引导脚本](安装引导脚本.md)导入 JSON 或通过 tavern_sync 打包 JS；同一张卡只选择一种方式。

## DVS 卡片作者

1. 按[最小角色卡示例](../../examples/dvs-minimal-card/README.md)导入并查看源文件。示例以书店店员林溪的好感度、时间地点和物品列表说明连续流程，不包含状态栏。
2. 按[DVS 作者手册](../dvs/指南/DVS作者使用手册.md)从设定、表结构和初值开始，配置世界书、酒馆助手脚本、`narrativePrepare` 和 `beforeGen` 两个必需回调，再核对正文输入、变量更新和查询。
3. 修改字段时同时调整 SQL、世界书、注册信息和回调；新聊天初始化与已有聊天升级分别处理。编辑器类型使用扩展包中的 `types/dvs.d.ts`。

需要减少每轮正文资料或预先安排剧情时，继续照着[输入增强示例](../dvs/指南/DVS作者使用手册.md#可选正文资料筛选与剧情规划)设置脚本开关、世界书标签、表格筛选宏和规划规则。功能默认关闭，最小卡不依赖它。玩家可以展开用户消息下的“输入增强”面板检查本轮结果，并对最新用户消息重新生成或清除；变量仍按最终生成的正文更新。

整理旧版标签和默认配置时，可用完整包的 `tools/dvs-card-migrate.mjs` 转换 `index.yaml`。只转换索引时，核对差异即可交付。准备分发新版卡时，再按原工程方式生成导入包，核对导入后实际使用的世界书和脚本配置。业务表结构升级另按 DDL 迁移处理。详见[旧卡转换指南](../dvs/指南/场景/旧卡转换.md)。

按具体操作开发卡片，先看[DVS 场景开发指南](../dvs/指南/DVS场景开发指南.md)。需要 AI 协助时，选择[SQLite Helper 与 DVS 开发 skills](卡片开发skill.md)中的总入口或专用入口。酒馆扩展安装与 AI 工具的 skill 安装是两件事，安装扩展不会自动向 AI 工具安装 skill。

## 共同限制

插件启用时，在酒馆单人聊天中新建分支或检查点会取得独立聊天库。已有分支沿用原聊天编号。当前不支持群聊、跨库事务或多设备同步。角色编号只保存在当前存储的管理库中；复制角色得到新文件名，作为新角色独立登记，不复制数据库。其他方式复制聊天时的独立编号、导入聊天的编号处理和完整备份恢复尚未提供。旧版插件管理结构不自动迁移；DVS 作者的业务表版本迁移另按作者手册操作。数据库查询成功只证明当前内存可读，不能代替重新打开文件后的保存读回；操作细节见[文件、升级与备份](../sqlite-helper/指南/使用与维护指南.md#文件升级与备份)。
