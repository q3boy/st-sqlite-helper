# 输入增强

## 筛选资料与剧情规划

先决定需要哪一项能力：

| 需要解决的问题 | 选择 |
| --- | --- |
| 世界书有很多本轮用不到的背景 | 世界书筛选；为候选设定使用 `[DVS:正文;可筛选]`，写清保留条件 |
| 物品或人物表很大，只想给正文相关行 | 变量行筛选；在具有预处理范围的条目中用四段数据宏声明选择组 |
| 希望正文先安排本轮行动和结束位置 | 剧情规划；用 `[DVS:剧情规划]` 提供规则，按需补字段要求 |
| 正文前要让玩家确认人设、购物或其他选择 | 生成拦截；在作者脚本注册交互组件，见[制作生成拦截界面](../../dvs-docs/references/generation-interception-guide.md#制作生成拦截界面) |

四项都可以单独启用。世界书筛选对应 `dvs.config.lb_opt.llm_filter`，表行筛选对应 `dvs.exts.tables_opt`，剧情规划对应 `dvs.exts.plot_plan`，生成拦截对应 `dvs.exts.pre_narr_ui`。保留基础扩展默认值，按卡片需要开启相应功能。玩家在酒馆“功能使用”中选输入增强的模型，切卡后沿用。

只给两种筛选共用的要求写 `[DVS:筛选规则]`；只适用于一方的分别写 `[DVS:世界书筛选规则]`、`[DVS:变量筛选规则]`。不必把同一段文字复制到三个条目。

例如筛选“本轮会用到的物品”，先写自然语言条件，再核对返回数据包含物品的完整业务键。模型负责选哪些行，正文中的数量仍取准备好的原值。变量更新继续使用完整起点，不因正文没展示某行而删掉该行。宏和配置的完整例子见[作者手册](../../dvs-docs/references/dvs-author-guide.md#可选正文资料筛选与剧情规划)。

改完先核对实际激活的条目和准备数据，再看选择结果。世界书根本未激活时，DVS 无法把它筛选回来。修改条件或规划规则后，主动重做输入增强再检查；普通重新生成正文可能复用已有结果。
