# 配置正文筛选与剧情规划

先读[筛选资料与剧情规划](references/input-enhancement-guide.md#筛选资料与剧情规划)，检查现有世界书、正文准备回调和脚本默认配置。

## 实施

1. 确定需要筛选世界书条目、筛选表行，还是安排本轮剧情。按需设置三项独立功能，保留其他配置及玩家选择；准确字段查[输入增强接口](../dvs-docs/references/dvs-api.md#输入增强接口)。
2. 为世界书条目选择请求范围。允许正文筛选用 `[DVS:正文;可筛选]`；条件说明何时保留，不能让筛选找回未被酒馆激活的内容。标签组合查[世界书用途](../dvs-docs/references/dvs-api.md#选择世界书条目的用途)。
3. 表行筛选使用四段数据宏，准备数据保留完整业务键。同一组条件保持一致；需要筛选的内容不要又在正文别处用全量宏重复输出。
4. 规则按用途写为共用、仅世界书或仅变量；同一段共用规则不复制成两份。规划只安排当前行动，区分计划与已发生事实，保留玩家决定。完整例子查[作者手册](../dvs-docs/references/dvs-author-guide.md#可选正文资料筛选与剧情规划)。

## 检查与交付

核对条目范围、启用与激活条件、宏分组、业务键及功能开关。说明关闭筛选时的数据、已有选择何时复用，以及改规则后怎样重新生成输入增强。交付索引、规则与必要回调，分别说明静态检查和实际请求观察；模型配置和真实酒馆调用另按授权执行。

需要完整接口或本场景以外的规则时，使用 `dvs-docs`，按问题查对应章节，不必通读全部手册。安装时保留配套资料包，见各包 `source.json` 的 `requires`。
