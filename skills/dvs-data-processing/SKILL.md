# 加工 DVS 数据与结算结果

先读[加工正文数据与计算结果](references/data-processing-guide.md#加工正文数据与计算结果)，检查现有表、业务规则和注册回调。先确定输出只用于表达，还是需要保存为下一轮状态。

## 选择处理位置

| 需求 | 处理 |
| --- | --- |
| 给正文显示阶段、描述或部分字段 | 在 `narrativePrepare` 返回副本中处理；保留筛选需要的完整业务键 |
| 为变量请求整理提示词数据 | 在 `beforeGen` 返回副本中处理；不改变真实起点 |
| 按公式计算需要保存的结果 | 在 `preUpdate` 中计算或订正真实表 |
| 需要模型额外提取本轮事件 | 按需声明虚拟表，再由 `preUpdate` 结算并删除虚拟表 |

## 实施

1. 将作者规则写成明确输入、公式和结果。例如模型判断已发生的收入与支出，代码负责加减；阈值、单位和舍入方式使用用户规则。
2. 派生字段只放入所需提示词或界面数据。数据库保留原始业务值；界面与正文使用相同转换规则时复用计算函数。
3. 结算从回调提供的完整 `oldTables` 起点计算，不从上次失败结果继续累加。保留其他真实表的合法改动；`preUpdate` 返回全部真实注册表及合法字段，清空表用空数组，返回前移除全部虚拟表。
4. 固定计算不必引入虚拟表。需要虚拟表时，规则只要求模型提供本轮发生的事件，避免再让模型同时计算并修改最终余额。

准确输入、返回值和重试行为查[回调参考](../dvs-docs/references/dvs-api.md#数据准备和更新回调)，字段处理查[预处理表数据](../dvs-docs/references/dvs-api.md#预处理表数据)，事件例子查[虚拟表结算](../dvs-docs/references/dvs-api.md#虚拟表输入与写库前计算)。

## 检查与交付

按实际公式检查阈值、单位、无事件及同一起点重复计算；核对提示词副本与待保存结果各自包含哪些字段。交付回调、同步后的规则和检查结果，说明未执行的模型或酒馆验证。

需要完整接口或本场景以外的规则时，使用 `dvs-docs`，按问题查对应章节，不必通读全部手册。安装时保留配套资料包，见各包 `source.json` 的 `requires`。
