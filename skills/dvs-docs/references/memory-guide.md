# 为角色卡配置记忆

一张古风探案卡需要记住到访过的衙署、渡口，以及尚未查清的案情。在卡片已有 DVS 注册脚本的脚本变量中合并以下字段，保留原有扩展和配置：

```json
{
  "dvs": {
    "enabled": true,
    "exts": { "memory": true },
    "config": {
      "memory": {
        "模块": {
          "地点资料": { "开启": true },
          "剧情线索": { "开启": true }
        }
      }
    }
  }
}
```

只有作者能启用记忆扩展。只需要逐楼摘要、阶段总结、故事背景，以及人物和地点经历时，给已接入 DVS 的卡设置 `dvs.exts.memory: true` 即可。四个可选模块默认关闭，按卡片需要开启：

| 希望长期记录什么 | 在 `dvs.config.memory.模块` 中开启 |
| --- | --- |
| 人物的外貌、身份等档案 | `角色资料` |
| 地点的特征和布局，如县衙的前堂、后院 | `地点资料` |
| 需要跟踪数量和状态的物件，如收押的物证 | `物品记录` |
| 待查、已触发或已完结的事项，如渡船失踪案 | `剧情线索` |

人物经历和人物关系会随剧情记录，地点经历也会记录。探案卡只开地点资料和剧情线索，仍能记住艄公认得谁、曾在渡口见过谁。

## 正文交代时间地点，记忆沿用卡片格式

如果卡片需要正文在换场或明显推进时间时交代时间和地点，可设置 `dvs.config.memory.时间地点要求` 为 `true`。卡内已有这类叙事规则时可省略。

记忆本身沿用材料中的历法和精度。例如正文只有“大昭十二年三月”，摘要也可以只记到月。作者另有排版要求时，设置字符串 `dvs.config.memory.写作要求`，例如“地点按‘州县·具体场所’书写，只知一层就只写一层。”逐楼摘要、阶段总结和故事背景共用这一要求。只指定地点格式时，时间继续沿用原文。

## 开场白与已有聊天

新聊天会自动建好记忆表。如果第一幕就有必须记住的旧案，可在匹配开场白的 `[DVS:初始化:memory]welcome_0` 条目中写入初值。无需预置时可省略整个条目。已有聊天首次启用会从空记忆表开始记录，之前的楼层不会自动补写。正文召回使用启用了 Chat History 的 Chat Completion 请求。[记忆扩展接口](dvs-api.md#记忆扩展)

## 查看本轮记忆

用户消息的“输入增强”中，“记忆筛选”列出入选楼层和实体。AI 回复的“正文分析”中，“记忆总结”显示本楼短总结、详细记忆字数，以及新增或更新的实体。点击条目可在记忆窗口定位查看当前内容。胶囊收起时分别显示入选总数，以及淡紫色的记忆字数、实体数标签。
