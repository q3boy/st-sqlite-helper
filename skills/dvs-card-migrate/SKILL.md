# 转换旧版 DVS 卡片写法

先读[旧版 DVS 卡片升级](references/migration-guide.md)，确认用户提供的是酒馆同步工具的 `index.yaml`。PNG／JSON 导入卡不能直接作为工具输入；需要对应的可编辑索引。

## 执行转换

1. 保留源文件副本或版本记录。工具原地写回指定索引，只转换条目名称和脚本默认配置。
2. 用 Node.js 运行本包 `scripts/dvs-card-migrate.mjs`，无需安装项目依赖。交互终端对每个旧筛选规则提供共用、仅世界书、仅变量三项。用户未要求改变范围时保留共用；无交互调用使用：

   ```sh
   node scripts/dvs-card-migrate.mjs "用户索引路径" --filter-rules common
   ```

   `worldbook`、`variables` 只在用户明确选择专用范围时使用。这里的相对脚本路径以本 skill 目录为准。

3. 读回工具输出和完整差异，核对条目数量、文件引用、激活设置、排列、配置及无关变量。报错时处理具体原因，不绕过无法无损转换的组合；工具成功只证明索引转换完成。
4. 只要求转换索引时，核对差异后交付索引。若任务包括调整卡片工程，按新名称同步受影响的自有打包工具、测试与说明。准备分发新版卡时，再按原工程方式更新卡片内容版本、生成并读回导入包。双括号内容宏、作者回调、业务表和历史聊天沿用原样。

## 交付

说明改了哪些标签和默认值、筛选规则选了什么范围、关联文件是否处理以及导入包是否生成。索引默认值不等于玩家当前变量；更新现用世界书和重载脚本的步骤交给作者按实际情况执行。仅改写法不新增 DDL 迁移，不重跑 INIT。

需要完整接口或本场景以外的规则时，使用 `dvs-docs`，按问题查对应章节，不必通读全部手册。安装时保留配套资料包，见各包 `source.json` 的 `requires`。
